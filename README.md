## Hey there, I'm slickvibes 👋

Most of what I build starts as a question I couldn't answer in lecture — a graph problem that felt wrong, a script that ran slower than it should, some Linux thing that broke at 2am. I write a lot of Python and Java, less C++ than I'd like, and I keep half-finished repos around because that's the only way the material actually sticks. Data structures are the part I keep circling back to; there's always a simpler way to hold the same data, and I like hunting for it.
